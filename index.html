End-to-end data pipeline, machine learning model evaluation benchmarks, and system architecture.

DATA ENGINE ARCHITECTURE PIPELINE

1. Raw Dataset

14,372 records, 10 features, missing/duplicate cleaning & outlier validation.

2. Feature Prep

Age derivation, annual mileage intensity, categorical encoding & standard scaling.

3. CatBoost Ensembles

Sequential gradient boosted oblivious decision trees with native categorical splits.

4. FASTAPI Routing

Asynchronous Server Gateway Interface (ASGI) deploying parallel threading.

5. SHAP XAI

Shapley additive explanations delivering local & global feature impact.
